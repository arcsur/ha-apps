# Changelog

## 1.0.0

- Initial release of Wyoming Whistle.
- Integrated Cactus Compute's 16.9MB ultra-lightweight offline Whistle speech-to-text model.
- Supports English, German, French, Spanish, Italian, Dutch, and Polish with automatic language detection.
- Native Wyoming protocol integration with Home Assistant Supervisor discovery and optional Zeroconf mDNS.
- Pre-packaged offline model weights and optimized C++ engine for fast local execution.
